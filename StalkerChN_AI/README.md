# ☢ StalkerChN_AI

**Голосовой AI-мод для S.T.A.L.K.E.R.: Чистое Небо / Зов Припяти — аналог CodoldAIValley из Stardew Valley.**

Вы говорите в микрофон → ближайший NPC **слышит вас**, отвечает вслух в своём характере
(бандит, долговцы, военные, Сидорович…) → а то, что он **услышал**, запоминается и влияет
на отношение этого NPC **и его союзников по фракции**. Оскорбили сталкера при его корешах —
получите вражду со всей группировкой. Поблагодарили торговца при свидетелях — слухи добры.

```
[Микрофон игрока] --PCM/WebSocket--> [Python-сервер ИИ]
                                        │  STT (faster-whisper / Vosk, ru)
                                        │  кто рядом слышал? (позиции NPC из игры)
                                        │  LLM (Ollama/OpenAI/Claude/mock) отыгрывает NPC
                                        │  TTS опционально (Kokoro/Piper/edge-tts)
                                        ▼
[X-Ray Lua-клиент] <--HTTP события-- [реплики, анимации, репутация фракций]
   субтитры · 3D-звук у NPC · play_action · change_goodwill
```

## Структура проекта

| Путь | Что это |
|---|---|
| `config/settings.ini` | Все настройки: STT/LLM/TTS, радиусы, пороги реакций |
| `scripts/server/main.py` | FastAPI + WebSocket сервер (ядро мода) |
| `scripts/server/stt.py` | Распознавание русской речи (whisper/vosk/openai) |
| `scripts/server/llm.py` | Генерация ответов NPC + парсинг JSON-действий |
| `scripts/server/prompts.py` | Персоны NPC, лор ЧН, память, реакции союзников |
| `scripts/server/npc_state.py` | Память отношений/фактов (`data/npc_memory.json`) |
| `scripts/server/tts.py` | Озвучка ответов (опционально) |
| `client/mic_bridge.html` | Микрофон-мост в браузере (PTT = клавиша V) |
| `game/scripts/AIValley/init.lua` | Клиент внутри игры (X-Ray Lua) |
| `docs/` | Установка, промпты, API |

## Быстрый старт (5 минут, без GPU)

```bash
cd StalkerChN_AI
python3 -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install fastapi "uvicorn[standard]" httpx numpy    # минимум для mock-режима
python scripts/server/main.py                          # сервер на 127.0.0.1:8765
```

В `config/settings.ini` для теста поставьте `backend = mock` в `[llm]` и любой локальный
STT. Затем:

1. Откройте `client/mic_bridge.html` в Chrome/Edge → «Подключить микрофон».
2. В игре скопируйте `game/scripts/AIValley/` и `game/gamedata/` в вашу сборку ЧН
   (подробности — `docs/INSTALL.md`).
3. Зажмите **V**, скажите ближайшему NPC «Здорово, братан!» — он ответит.
4. Скажите бандиту «ты чё тут делаешь, бандюга ебучий?» — обидится не только он,
   но и его кореш рядом, и вся фракция узнает.

### Реальный интеллект (рекомендуется)

* **LLM бесплатно и офлайн:** установите [Ollama](https://ollama.com), затем
  `ollama pull qwen2.5:7b-instruct` (русский) или `ollama pull llama3.1:8b`.
  В конфиге `[llm] backend = ollama` уже настроен.
* **STT офлайн:** `pip install faster-whisper` (модель `small` подтянется сама).
  Для слабого ПК: `pip install vosk` + модель
  [vosk-ru-0.42](https://alphacephei.com/vosk/models).
* **Голоса NPC:** `pip install edge-tts` и в `[tts] enabled = true, backend = edge`
  (или Kokoro/Piper — см. `docs/TTS.md`).

## Как это работает (детали)

1. **Слышимость.** Lua-клиент каждые 0.5 с шлёт серверу позицию игрока и список
   живых NPC в радиусе 37 м (id секции, имя, фракция, координаты, здоровье).
   Сервер считает, кто реально мог услышать голос (радиус `faction_alert_radius`).
2. **Ответ ближайшего.** Самый близкий NPC получает системный промпт-персону
   (характер фракции + личное отношение −100..+100 + память фактов о вас + история
   диалога + факт «это также слышали N союзников») и отвечает строгим JSON:
   `{say, mood_delta, action, remember}`.
3. **Эффект свидетелей.** `action ∈ {offended, aggressive, alert_faction}` →
   все слышавшие союзники злятся, получают факт «Слышал, как ты обидел X», репутация
   фракции падает; Lua применяет это к goodwill-таблице сообщества. Дружелюбие,
   наоборот, растёт у всех присутствующих.
4. **Память.** `data/npc_memory.json` переживает перезапуски: NPC помнит ваши слова
   и через игровой день, и через неделю реальных.

## Конфигурация отношения (кратко)

Шкала −100…+100 за каждого NPC + агрегат по фракции. Пороги в `[reaction]`:
`offended_threshold=-25`, `friendly_threshold=+35`, `aggressive_threshold=-55`.
Кулдаун реакции 8 с — NPC не отвечает на каждое слово подряд, как живой человек.

## Совместимость

* Моделировалось под стоковое **Чистое Небо 1.0006 / ЗП** и современные сборки
  (SRP CoC, ZRP-подобные). Lua-клиент защищён `pcall`-ами: при отсутствии API
  (например, HTTP-шлюза) мод деградирует до субтитров/лога, а не крашит игру.
* Точные имена функций X-Ray различаются между билдами — в `init.lua` предусмотрены
  ветки `xr_http` / `luaxr.http` / `luasocket` и `alife_change_goodwill` /
  `change_relation_to_community`. См. `docs/INSTALL.md`.

## Дисклеймер

* Проект фанатский, не связан с GSC Game World и авторами CodoldAIValley.
* Голос отправляется только на локальный сервер (127.0.0.1); при облачном STT/LLM
  фразы уходят провайдеру — смотрите `[logging] log_transcripts`.
* Модель может сказать что-то неканоничное — правьте каркас поведения в
  `scripts/server/prompts.py`.
