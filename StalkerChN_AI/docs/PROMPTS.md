# Промпт-система StalkerChN_AI

Всё собирается в `scripts/server/prompts.py`. Идея как в CodoldAIValley: у каждого
NPC — своя «личность», память и характер, но поверх лора Чистого Неба.

## Слои промпта

1. **WORLD_SYSTEM** — жёсткий каркас: не выдавать себя за ИИ, короткие реплики,
   жаргон Зоны, строгий JSON-ответ.
2. **SAFETY_SUFFIX** (вкл. `llm.safety_prompt=on`) — запрет реальных вредных
   инструкций + переспрос при мусорном распознавании.
3. **Персона NPC**:
   * `profile` из снапшота игры (если сборка отдаёт описание);
   * иначе шаблон по фракции (`ROLE_TEMPLATES`: dolg/freedom/bandit/army/duty/
     monolith/ecologist/merc/trader/mechanic/barkeep/neutral).
4. **Текущее состояние**: личное отношение −100..+100 → 5 градаций тона;
   здоровье < 45% → стонущая речь.
5. **Память**: последние ≤10 фактов (`remember` из прошлых ответов) + история
   диалога (последние 12 реплик).
6. **Контекст свидетелей**: во user-блоке пишется, кто ещё слышал фразу, —
   модель сама понимает риск «услышат союзники».

## Как менять поведение

* Тон короче/длиннее → `max_tokens`, правило «1–3 предложения» в WORLD_SYSTEM.
* Больше канона — добавьте в `ROLE_TEMPLATES` описания конкретных персонажей
  (Сидорович, Кардан, Скелечник…) с ключом по id секции профиля; `profile` из
  игры всегда приоритетнее шаблона.
* Жёстче к оскорблениям — увеличьте отрицательный `mood_delta` в RULES mock'а
  или правьте safety-строки; пороги реакций — `[reaction]` в settings.ini.
* Реакции подслушавших союзников (без LLM-вызова, чтобы не плодить запросы) —
  таблица `ALLIES_REPLIES`; расширьте её своими фразами.

## Отладка

```bash
curl -s localhost:8765/api/state/stalker_bandit_0001 | python -m json.tool
tail -f logs/stalkernn.log        # видно транскрипт -> say -> action
```

Для тонкой настройки модели: поставьте `llm.backend=openai` c локальным
LM Studio и temperature 0.7–1.0; для быстрых тестов логики мода — `mock`.
